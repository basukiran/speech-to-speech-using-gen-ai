# 🎙️ Speech-to-Speech Generative AI for Assistive Devices

An AI-powered speech-to-speech communication system designed to improve accessibility by enabling real-time speech recognition, translation, and audio playback. This project aims to assist users in overcoming language and communication barriers through intelligent voice processing.

---

## 🚀 Features

- 🎤 Voice Recording
- 📝 Speech-to-Text Conversion
- 🌐 Language Translation
- 🔊 Text-to-Speech Output
- ⚡ Real-Time Processing
- ♿ Accessibility-Focused Design

---

## 🛠️ Technologies Used

- Python
- Generative AI
- Speech Recognition
- Text-to-Speech (TTS)
- Translation APIs
- HTML
- CSS
- Flask

---

## 📌 Project Overview

This application allows users to record speech in one language, convert it into text, translate the text into another language, and generate spoken audio output from the translated text.

The project focuses on assistive technology applications and demonstrates how Artificial Intelligence can be leveraged to improve communication and accessibility.

---

## 🎯 Objectives

- Improve communication accessibility.
- Reduce language barriers through automated translation.
- Explore practical applications of Generative AI and speech technologies.
- Provide an intuitive and user-friendly interface for voice interaction.

## 🔄 Workflow

1. User records speech.
2. Speech is converted to text.
3. Text is translated into the selected language.
4. Translated text is converted back into speech.
5. Audio output is played to the user.
